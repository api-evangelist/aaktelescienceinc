# AAK Tele-Science, Inc.

> AAK Tele-Science, Inc. (aakscience.com) is a Davis, California software company founded in 2020 that runs a cloud-based collaborative platform for the global scientific research community. The platform connects researchers, research institutions, service providers, venture capitalists and investors around shared projects, adding machine-learning-assisted discovery, predictive analytics and a data-fragmentation privacy protocol on top of a subscription SaaS product.

## API surface

**There is no public API.** AAK Tele-Science operates a real REST API — the web application
preconnects to `https://django.aakscience.com` and the company runs a Django/drf-yasg backend
that exposes Swagger schema endpoints — but none of it is reachable without credentials:

- `https://django.aakscience.com/` and every path beneath it return **HTTP 401** with a
  zero-length body, including paths that do not exist, so the wall is at the edge and no
  route can be confirmed from outside.
- The drf-yasg schema endpoints answer **`Swagger authentication required`** (HTTP 401).
- No OpenAPI, AsyncAPI, GraphQL SDL, JSON Schema, Postman collection, MCP server or A2A agent
  card is published at any location probed on aakscience.com, www.aakscience.com,
  django.aakscience.com or django-dev.aakscience.com.
- No developer portal, documentation host or API reference exists. The company's own
  sitemap.xml lists only marketing, registration, legal and subscription routes.

If you are an agent trying to integrate with AAK Tele-Science, there is nothing to call. The
path forward is a sales or partnership conversation via https://aakscience.com/contact.
